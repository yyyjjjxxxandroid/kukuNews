项目简介：（正在开发中）一款仿头条的app　　Github地址:https://github.com/yyyjjjxxxandroid/kukuNews

功能简介：动态申请权限，隐私弹窗，初次进入展示轮播图界面，进入首页后，自动加载广告图片，加载好广告图片后下一次进入将会跳出广告（封装好webview点击广告跳转）以及广告倒计时，封装网络框架接受服务端信息实现类似头条的推荐页面（标题、内容、评论、作者、发布时间（日期格式化）），以及点击item进入详情页，图片预览功能、登入功能（验证码登入和密码登入）、注册功能（注册完后自动登入），发布功能（发布文字、图片），侧滑菜单，上拉刷新和下拉加载更多。

技术要点：1.利用Handler进行线程切换和ExecutorService创建线程池进行异步任务实现图片压缩

　　　　　2.封装Retrofit框架，通过设置拦截器实现登入请求头传递，配置缓存，超时设置

　　　　　3.ViewPager2 嵌套 ViewPager2 ，解决了滚动冲突。

　　　　　4.实现文件上传至阿里云，并用密封类封装返回类型更新图片上传进度到加载dialog中

　　　　　5.给广告的的跳转按钮添加闪光效果

　　　　　6.在发布图片时实现类似iPhone系统加载dialog动画

　　　　　7.实现Parcelable接口用于在activity之间传递数据

　　　　　8.在AppContext中初始话各种配置，以及封装好mmkv工具类保存用户偏好

　　　　　9.利用Flow配合协程进行异步数据流处理，利用LiveData实现数据自动更新

　　　　　10.项目严格遵循MVVM的设计模式。
